
# IT202 Project 2 — Moving On Up

## Project Description
Moving On Up is a moving company management website developed using HTML, CSS, JavaScript, PHP, and MySQL.

This project builds upon Project 1 by implementing database authentication and six moving company transactions.

## Features
1. Representative login and account search
2. Book a client's moving event
3. Cancel a client's moving event
4. Add special instructions
5. Update special instructions
6. Create a new client account

## Technologies Used
- HTML5
- CSS3
- JavaScript
- PHP 8.4
- MySQL 8.0
- MySQL Workbench

## Database
The moving_on_up database contains five tables:
- moving_representatives
- clients
- client_personal_information
- moving_events
- special_instructions

## Testing
The website was tested locally using PHP's development server and MySQL.
