# IT 202 – Project 1: Moving On Up

## Phase 1 – HTML and CSS

This project is a login webpage for a moving company called Moving On Up (MOU).

The webpage includes representative information fields, a password field, an email confirmation checkbox, a transaction dropdown, and Submit and Reset buttons.

The website was developed using HTML and CSS and includes a moving van background image.
